# SurvivalCraft-API iOS версия с поддержкой плагинов

## Описание проекта
SurvivalCraft-API — это фреймворк для разработки плагинов для игры SurvivalCraft на платформе iOS, предоставляющий полный набор API-интерфейсов, позволяющих разработчикам создавать и разрабатывать плагины для iOS-версии игры SurvivalCraft.

## Системные требования

### Рабочая станция под Windows
- Visual Studio 2022
- Компоненты разработки Xamarin.iOS
- Среда разработки .NET

### Платформа сборки Mac
- macOS 11.0 или выше
- Xcode 13.0 или выше
- Учетная запись Apple Developer

## Настройка окружения

### 1. Подготовка ресурсных файлов
Упакуйте ресурсные файлы Windows-версии:

```bash
# Упакуйте каталог Survivalcraft.Windows\Content в zip-файл
```

### 2. Подготовка проекта

1. Откройте файл решения с помощью Visual Studio 2022:
   ```
   SurvivalcraftApi.sln
   ```

2. Создайте отладочную версию для Windows-платформы (важный шаг):
   - Установите `Survivalcraft.Windows` в качестве стартового проекта
   - Выберите конфигурацию Debug и платформу x86/x64
   - Соберите решение
   
   *Примечание: этот шаг необходим, пропуск может привести к потере ресурсных файлов в iOS-версии и появлению белого экрана.*

### 3. Настройка окружения macOS

#### Создание проекта и настройка Bundle Identifier

1. При создании проекта в Xcode убедитесь, что Bundle Identifier совпадает с CFBundleIdentifier в Info.plist
2. Рекомендуемый формат Bundle Identifier: `com.survivalcraft.api.y251026`
3. См. следующий скриншот для настройки:

![Bundle Identifier](docs/bundle.png)

#### Управление сертификатами и профилями подготовки

1. Просмотреть доступные сертификаты подписи:
   ```bash
   security find-identity -p codesigning
   ```

2. Просмотреть локальные профили подготовки:
   ```bash
   ls -lh /Users/[username]/Library/MobileDevice/Provisioning\ Profiles/
   ```

3. Просмотреть кэш учетных данных входа в Xcode:
   ```bash
   ls -lh /Users/[username]/Library/Preferences/com.apple.dt.Xcode.plist
   ls -lh /Users/[username]/Library/Developer/Xcode/UserData/
   ```

#### Очистка информации об старой учетной записи (при необходимости смены учетной записи разработчика)

1. Удалить сертификаты старой учетной записи (по значению SHA1):
   ```bash
   security delete-identity -Z <SHA1_старого_сертификата>
   ```

2. Удалить старые профили подготовки:
   ```bash
   rm -rf /Users/[username]/Library/MobileDevice/Provisioning\ Profiles/*
   ```

3. Очистить информацию о входе в Xcode:
   ```bash
   rm -f /Users/[username]/Library/Preferences/com.apple.dt.Xcode.plist
   rm -rf /Users/[username]/Library/Developer/Xcode/UserData/Provisioning\ Profiles
   rm -rf /Users/[username]/Library/Developer/Xcode/UserData/XcodeCloud
   ```

#### Решение проблемы несоответствия путей к профилям подготовки между Visual Studio и Xcode

Новые версии Xcode изменили место хранения профилей подготовки. Чтобы гарантировать, что Visual Studio может правильно найти профили подготовки, нам нужно создать символические ссылки:

```bash
# Удалить старую папку (если она существует)
rm -rf ~/Library/MobileDevice/Provisioning\ Profiles

# Создать символическую ссылку, соединив старое местоположение с новым
ln -s ~/Library/Developer/Xcode/UserData/Provisioning\ Profiles ~/Library/MobileDevice/Provisioning\ Profiles

# Проверить, успешно ли создана ссылка
ls -l ~/Library/MobileDevice/
```

## Сборка iOS-проекта

### 1. Подключение платформы сборки Mac
Настройте удаленную сборку на Mac в Visual Studio:
- Перейдите в `Сервис > iOS > Сопоставить с Mac`
- Введите IP-адрес Mac, имя пользователя и пароль
- Дождитесь успешного подключения

### 2. Сборка iOS-проекта

1. Установите `SurvivalCraft.IOS` в качестве стартового проекта
2. Выберите конфигурацию Debug и платформу iPhone Simulator или iOS Device
3. Нажмите кнопку сборки или нажмите F5 для запуска


### Создание ipa
1. Выберите:
   - Установите `Survivalcraft.Windows` в качестве стартового проекта
   - Выберите конфигурацию Release и платформу x86/x64
   - Соберите решение

2. Затем вернитесь к SurvivalCraft.IOS:
   - Выберите его в качестве стартового проекта
   - Создайте архив

## Часто задаваемые вопросы

### 1. Сборка не удалась, отображается ошибка отсутствия профиля подготовки
- Убедитесь, что вы создали правильный App ID в Apple Developer Portal
- Убедитесь, что вы загрузили самые свежие профили подготовки в Xcode
- Проверьте, корректно ли создана символическая ссылка

### 2. Белый экран после запуска
- Убедитесь, что вы сначала создали версию для Windows-платформы
- Проверьте, корректно ли упакованы и загружены ресурсные файлы

### 3. Ошибки, связанные с сертификатами
- Убедитесь, что учетная запись разработчика действительна и не просрочена
- Проверьте, корректно ли установлены сертификаты на Mac
- Попробуйте очистить и заново загрузить сертификаты и профили подготовки

## Руководство по разработке плагинов

Для разработки плагинов для iOS-платформы следуйте этим шагам:

1. Создайте новый проект Class Library в решении
2. Добавьте ссылки на необходимые API-ассемблии
3. Реализуйте интерфейсы и функциональность плагинов
4. Поместите скомпилированные плагины в указанный каталог

Детальная документация по разработке плагинов см. в соответствующих инструкциях главного проекта.
